# Noms candidats — remplacer « ShiftMaster »
> Last update: 2026-10-01

Consigne de Serge (01/10/2026) :
- Le nom vient d'une référence culturelle très connue, seule ou associée à un seul mot descriptif.
- Il peut être long s'il est bien trouvé.
- On écarte tout nom déjà porté par un outil existant.
- Le mot « shift » n'est pas obligatoire.
- On creuse les références en profondeur.

Vérifications du 01/10/2026 :
- **Domaines** : registres officiels (RDAP Verisign pour .com, Google Registry pour .app). « pris » veut dire enregistré ; je n'ai pas vérifié s'il est à vendre.
- **Usage existant** : recherches web en mode standard, faites depuis les États-Unis. Les noms à consonance française ont aussi été cherchés en français. « Rien trouvé » veut dire rien vu dans ces recherches.
